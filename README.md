# 📱 TechNews Today — Portal de Tecnologia

## 📌 Sobre o Projeto

O **TechNews Today** é um portal de notícias sobre tecnologia desenvolvido com **HTML5 e CSS3**. O projeto tem como objetivo aplicar os conceitos de estrutura semântica do HTML, estilização moderna com CSS e organização de conteúdo em uma página web.

A página apresenta um artigo em destaque sobre Inteligência Artificial, uma seção de vídeo e um formulário para inscrição em uma newsletter.

## 🎯 Objetivos

- Aplicar as tags semânticas do HTML5.
- Organizar conteúdos utilizando elementos estruturais.
- Desenvolver uma interface moderna e visualmente agradável.
- Utilizar CSS para cores, gradientes, efeitos e espaçamentos.
- Implementar um formulário com campos de preenchimento obrigatório.
- Aplicar conceitos de responsividade com CSS Grid e Media Queries.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** estruturação do conteúdo da página.
- **CSS3:** estilização, gradientes, animações e responsividade.
- **YouTube:** incorporação de vídeo por meio da tag `iframe`.
- **PHP:** destino configurado para o processamento do formulário por meio do arquivo `subscribe.php`.

## 📂 Estrutura do Projeto

```text
TechNews-Today/
├── index.html
├── 10a_desafio.css
└── subscribe.php
```

**Observação:** o arquivo `subscribe.php` deve existir e conter a lógica de processamento do formulário para que a inscrição funcione. A estrutura acima representa os arquivos esperados pelo código.

## ✨ Funcionalidades

### 📰 Artigo em Destaque
Apresenta uma notícia sobre o impacto da Inteligência Artificial no desenvolvimento de software, incluindo data de publicação e uma área expansível com mais informações.

### 📺 Seção de Vídeo
Exibe um vídeo incorporado do YouTube, permitindo ao visitante acessar conteúdo audiovisual relacionado à tecnologia.

### 📧 Newsletter
Disponibiliza um formulário de inscrição com os seguintes campos:

- E-mail;
- Área de interesse;
- Aceitação dos termos;
- Botão para realizar a inscrição.

Os campos de e-mail e aceitação dos termos utilizam o atributo `required` para exigir o preenchimento antes do envio.

### 🎨 Design e Responsividade
O CSS utiliza uma paleta de cores escuras, gradientes, bordas arredondadas, efeitos de interação e organização com CSS Grid. Uma Media Query adapta a disposição do conteúdo para telas com largura mínima de 768 pixels.

### 📍 Rodapé
Apresenta informações de direitos autorais e um endereço de e-mail para contato.
